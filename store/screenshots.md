# Screenshot & promo asset plan

Chrome Web Store needs **≥1 screenshot at 1280×800** (or 640×400). Below is a
recommended set. Capture on a clean profile with the extension loaded unpacked.

## Screenshots (1280×800)

1. **Caught in the act.** On an AI chat page, paste text containing an API key +
   email with mode = Warn. Capture the PasteFilter dialog listing the findings.
   Caption idea: "See exactly what you're about to leak."

2. **The popup.** Click the toolbar icon. Show the four modes, the per-site
   pause, and type something into the "Try it" box so the live preview shows a
   randomized result. Caption: "Block, mask, or randomize — your call."

3. **Randomize toast.** With mode = Randomize, paste a credit card + IBAN and
   capture the toast ("Randomized 2 sensitive items"). Caption: "Realistic fake
   data in, real secrets never out."

4. **Settings, dark mode.** The options page with detector toggles visible.
   Caption: "18 detectors, all local. Light & dark."

## Promo tiles (optional, boosts placement)

- Small promo tile **440×280** — icon on a SEOULTRA-blue (#1a73e8) field with the
  wordmark "PasteFilter" and tagline "Redact & randomize as you paste."
- Marquee **1400×560** — same lockup, wider.

## Brand

- Accent blue: `#1a73e8` (light), `#4c8dff` (dark).
- Icon source: `assets/icon.svg` (shield + funnel + scrambled dots).
- Keep copy generic — no keyword lists (Chrome Web Store flags keyword spam).
