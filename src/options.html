PasteFilter
Welcome to PasteFilter.

PasteFilter watches what you paste into web forms and chat boxes. When it spots an API key, password, or personal detail, it can warn you, mask it, or swap in realistic fake data — all on your device. Nothing is ever sent anywhere.

Behavior

How PasteFilter reacts when it detects sensitive data in a paste.

Default action
Clean action (Warn / right-click)
Theme
Show toast after cleaning

Secrets to detect

Credentials and keys. All on by default.

Personal data to detect

PII validated locally (Luhn for cards, mod-97 for IBAN, range checks for IPs).

Paused sites

PasteFilter does nothing on these hostnames.

Allowlist patterns

One regular expression per line. Text matching any pattern is never flagged (e.g. @mycompany\.com$ or TEST-\d+).
